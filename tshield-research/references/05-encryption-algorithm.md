# 加密算法逆向与复现

## 1. 概述

T盾 的加密算法用于加密每个函数的代码。逆向加密算法是静态脱壳的关键。

### 1.1 可能的加密算法

| 算法类型 | 特点 | T盾 使用可能性 |
|----------|------|----------------|
| XOR | 简单，速度快，密钥固定 | 中 |
| AES | 安全性高，速度较慢 | 低（函数级加密需要速度） |
| 自定义流密码 | 速度快，定制化 | 高 |
| RC4 | 速度快，实现简单 | 中 |
| 字节替换+置换 | 自定义，难以识别 | 高 |

### 1.2 函数级加密的特点

- 每个函数独立加密
- 加密粒度：函数（通常几十到几百字节）
- 解密速度要求高（运行时实时解密）
- 可能使用函数ID作为密钥的一部分

## 2. 逆向加密算法的方法

### 2.1 动态分析方法（推荐）

#### 方法1：对比解密前后的内存

1. 在统一解密器入口下断点
2. 记录加密函数代码的地址和大小
3. dump 加密的代码
4. 单步执行解密函数
5. dump 解密后的代码
6. 对比加密前后的数据，推断加密算法

```gdb
break *0x4b7e3c8
commands
    silent
    # 记录函数ID
    set $func_id = *(unsigned int*)($sp + 0x??)
    printf "func_id = 0x%x\n", $func_id
    # 继续执行到解密函数返回
    continue
end

# 在解密函数返回后 dump 内存
break *0x4b7e47c
commands
    silent
    # dump 解密后的函数
    # x/64x $x0  (假设 x0 是解密后地址)
    continue
end
```

#### 方法2：单步跟踪解密函数

1. 在 `bl #0x5a90278`（解密子函数）处下断点
2. 单步执行，观察：
   - 密钥从哪里加载
   - 加密数据从哪里读取
   - 进行了什么运算（XOR/ADD/SUB/移位）
   - 结果写到哪里
3. 记录算法流程

### 2.2 静态分析方法

#### 方法1：去混淆后反汇编

1. 用符号执行工具（angr/miasm）去混淆统一解密器
2. 反汇编解密子函数 0x5a90278
3. 识别加密算法的特征：
   - 大量 XOR → XOR/流密码
   - S盒查找 → AES/字节替换
   - 移位+异或 → RC4/自定义流密码
   - 固定密钥加载 → 固定密钥算法

#### 方法2：已知明文攻击

如果知道某个函数解密后的代码（如函数序言 `stp x29, x30, [sp, #-0x20]!`），可以：
1. 找到这个函数的加密代码
2. 用已知明文 XOR 密文，得到密钥流
3. 分析密钥流的规律，推断密钥生成算法

```
已知明文: f8 5f bc a9 (stp x29, x30, [sp, #-0x20]!)
密文:     ?? ?? ?? ??
密钥流:   明文 XOR 密文
```

## 3. 常见加密算法的识别特征

### 3.1 XOR 加密

```c
// 特征：简单的循环 XOR
for (int i = 0; i < size; i++) {
    data[i] ^= key[i % key_size];
}
```

**识别特征**：
- 反汇编中有 `eor` 指令
- 循环结构简单
- 密钥长度固定

### 3.2 RC4

```c
// 特征：S盒初始化 + 密钥流生成
void rc4_init(unsigned char *s, unsigned char *key, int len) {
    for (int i = 0; i < 256; i++) s[i] = i;
    int j = 0;
    for (int i = 0; i < 256; i++) {
        j = (j + s[i] + key[i % len]) % 256;
        swap(s[i], s[j]);
    }
}
```

**识别特征**：
- 有 256 字节的 S盒初始化
- 大量模 256 运算
- 交换操作

### 3.3 AES

**识别特征**：
- S盒（256字节查找表）
- 轮常数（Rcon）
- 固定的轮数（10/12/14）
- 列混合、行移位、字节替换操作

### 3.4 自定义流密码

**识别特征**：
- 状态变量（多个寄存器）
- 非线性运算（乘法、模运算）
- 反馈机制
- 定制化的移位和异或

## 4. 复现加密算法

一旦逆向出加密算法，需要：

1. **提取密钥**：
   - 固定密钥：从二进制中提取
   - 函数ID派生密钥：分析密钥生成算法
   - 运行时密钥：动态分析获取

2. **编写解密脚本**：
   ```python
   def decrypt(encrypted_data, func_id):
       # 1. 生成密钥（可能基于 func_id）
       key = generate_key(func_id)
       # 2. 解密
       return decrypt_algorithm(encrypted_data, key)
   ```

3. **批量解密所有函数**：
   - 遍历映射表
   - 对每个函数调用解密函数
   - 保存解密后的代码

4. **验证**：
   - 反汇编解密后的代码，看是否是有效指令
   - 检查函数序言是否正常
   - 与动态 dump 的结果对比
