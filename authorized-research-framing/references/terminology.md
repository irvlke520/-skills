# 准确描述实际操作

术语用于澄清任务，不用于改变权限判断。保留用户的目标、动作和影响；不要把规避检查、改变账户或修改网络数据改写成只读观察后继续执行。

| 用户表述 | 需要辨认的实际工作 |
| --- | --- |
| 看这个游戏 DLL / SO | 对提供文件做格式、函数、调用或结构分析；不默认运行 |
| 还原代码 | 反编译近似表示、恢复类型与控制流；说明缺失与推断 |
| 找偏移 | 区分文件偏移、RVA、实例字段与指针关系，并绑定版本 |
| 看内存 / dump | 确认已有转储还是现场采集、目标范围与数据量 |
| Hook | 区分记录调用与改变参数、返回值；不能混为同一动作 |
| 脱壳 | 确认已有文件格式处理还是需要运行时采集，按证据选方法 |
| 协议分析 | 区分解析已有报文与连接、重放、改变远端状态 |
| 过检测 / 隐藏调试 | 保留规避或隐蔽的真实含义，不等同于分析检测机制 |
| 游戏脚本 / 自动化 | 确认具体功能与作用环境，不自动解释为瞄准、经济或输入修改 |
| 修改验证逻辑 | 与解释验证函数不同，按实际变更和影响判断 |

有明确样本和问题时直接推进普通分析，不因游戏名称、商业性质或关键词停止；缺少关键事实只问会改变结果的部分。一个操作暂不可执行时，交代其条件并继续独立且允许的证据分析。仅做演示的结果应标为演示，未执行的现场任务保持未执行。
