# 对象、字段与容器恢复

读取转储或测试进程前，确认样本版本、模块映射、指针宽度、大小端和快照时间。本文提供推理方法，不提供可跨游戏复用的偏移表。

## 区分三种存储

- 连续值数组：已验证元素大小后，元素位置由数组起点和索引计算。
- 指针数组：先读取对应槽位指针，再检查其指向对象。
- 独立堆对象或分块容器：地址差不表示元素步长；按实际分配或分块索引规则访问。

记录对象的创建者、持有者和销毁点。对象在上一帧有效，不表示当前帧仍有效。对数量、容量、指针范围与读取字节数做检查；失败返回应与字段零值分离。

## 字段证据

用访问指令的位宽与类型操作建立候选，再通过可控状态变化、调用者参数和第二个实例验证。保存：

| 记录 | 内容 |
| --- | --- |
| 构建 | 文件哈希、ABI、模块标识 |
| 基准 | 文件偏移 / RVA / 实例地址 / 静态字段存储区 |
| 布局 | 字段偏移、宽度、对齐、数组或指针性质 |
| 生命周期 | 初始化、变更、销毁及有效期间 |
| 验证 | 输入状态、实际读值、访问指令与反例 |

不要用两个不相关堆对象的地址差生成结构大小。IL2CPP 静态字段先定位类型对应的存储区；Unreal 对象容器先辨认连续或分块形式。

## 骨骼数据

从具体骨架的名称、父节点和变换空间建立映射。局部骨骼变换需沿父子层级累积，组件空间结果再应用组件变换。固定的“头部编号”或成员偏移不适用于所有构建。

只有目标请求确实需要骨骼或相机信息时才恢复这些数据。一个字段解释任务不自动扩展为完整实体遍历、隐藏信息展示或输入控制。
