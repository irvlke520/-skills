# T3 对抗报告模板

> 每做完一轮实测就填一份，别指望事后回忆。三把锁是靠一轮轮失败试出来的，
> 每份报告里最有价值的是"失败的那组对照数据"。

## 1. 目标

- 样本：路径 / 大小 / sha1
- 加固：壳类型、版本（例：T-Protector / T盾 1.0.25）
- 验证服务器：域名 / IP 池（**动手前重新抓一次，IP 会变**）
- 设备：机型 / Android 版本 / root 方案（KernelSU / Magisk）/ 是否有 su
